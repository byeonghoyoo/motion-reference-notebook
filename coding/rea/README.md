# REA 실사용 가이드

두 유튜브 영상의 제공된 설명과 REA 공식 자료를 구분해 정리한 한국어 학습 페이지입니다.

- 12개 장과 단계별 프롬프트 10개
- 모바일 목차, 본문 검색, 프롬프트 복사, 브라우저별 학습 체크
- JavaScript를 끈 경우에도 전체 본문 표시
- 영상 수치는 설명글 기준, 설치·지원 조건은 공식 문서 확인
- 실제 앱 역분석 실험이나 전체 영상 시청을 수행한 결과물은 아닙니다.

`index.html`에는 본문·CSS·JavaScript가 모두 들어 있습니다. 다운로드 후 단독으로 열어 읽을 수 있습니다. 외부 링크 이동에는 인터넷이 필요합니다. 복사는 HTTPS에서 가장 안정적으로 작동하며 실패하면 수동 복사할 텍스트를 선택합니다.

## 수정 및 재생성

`REA-실사용-가이드.md`가 본문 원본입니다. 화면 스타일은 `styles.css`, 상호작용은 `app.js`에 있습니다. Node.js가 있는 환경에서 다음을 실행합니다.

```sh
npm install
npm run build
```

생성된 `index.html`을 함께 커밋합니다. 빌드에는 marked가 필요하지만 배포된 페이지에는 외부 런타임 의존성이 없습니다. 문서는 임의 사용자 입력을 렌더링하지 않으며, 빌드 입력은 검토한 Markdown만 사용합니다.

## 확인한 것

12개 장·프롬프트 10개, 모든 명령/프롬프트 블록 보존, 중복 ID·내부 링크, JavaScript 문법을 검사했습니다. 실제 브라우저 렌더링·터치·클립보드 동작 검사는 수행하지 못했습니다. REA 설치나 예제 분석을 실제 실행한 것은 아닙니다.

읽기 진도는 현재 브라우저 localStorage에만 저장합니다. 서버 전송·분석 추적 코드는 없습니다. 영상 및 인용 자료의 권리는 각 권리자에게 있습니다.
