01목표: 혼자서 바로 사용
01 / FIRST RUN

처음엔 이것만 기억해.

명령어와 프롬프트를 입력하는 위치부터 구분하면 절반은 해결돼.

STEP 01 MAC TERMINAL

프로젝트 폴더로 이동

맥에서 ⌘ + Space → Terminal. 작업하려는 코드가 있는 폴더로 이동해.

cd /프로젝트/실제/경로
경로는 프로젝트에 맞게 바꿔야 해.
STEP 02 MAC TERMINAL

Claude Code 시작

같은 터미널 창에서 claude를 입력하면 AI 코딩 대화가 시작돼.

claude
스킬을 설치한 후에는 기존 Claude 세션을 재시작.
STEP 03 CLAUDE 대화창

작업부터 설명

AI가 사용할 도구를 고르게 하고, 기존 코드 백업과 결과 검증을 먼저 요구해.

현재 프로젝트를 읽고 알맞은 도구를 선택해 줘. 기존 기능을 보호하고, 먼저 작업 계획과 검증 기준을 보여 줘.
💡 입력 위치 구분터미널은 docker ps, 21st search 같은 실행 명령. Claude 대화창은 자연어 프롬프트와 /spec, /graphify . 같은 스킬 명령이야.

06 / PROMPT LIBRARY

그대로 복사하는 범용 프롬프트.

프롬프트에는 목적·제약·결과물·검증 기준을 넣었어. [대괄호] 부분만 실제 상황에 맞게 바꾸면 돼.

프롬프트를 선택하면 전체 내용이 여기에 표시돼.

07 / PERSONAL PROMPT BUILDER

내 작업에 맞는 프롬프트 생성기.

선택하고 몇 글자만 입력하면, AI에 그대로 보낼 작업 지시문을 만들어 줘. 생성은 이 브라우저 안에서만 이루어져.

✧ GENERATED PROMPT
왼쪽 항목을 입력하면 여기에 맞춤형 프롬프트가 표시돼.

API나 로그인 없이 작동하는 로컬 프롬프트 조합기야. 사이트에 입력한 내용은 서버로 전송하지 않아.

08 / TROUBLESHOOTING

막혔을 때 이렇게 해결.

병원 맥에서 실제 겪었던 인증·명령어·연결 문제를 포함했어.

안전한 사용 원칙

API 키·비밀번호·환자 정보를 프롬프트나 공개 GitHub에 올리지 말기. 라이브 서비스의 DB·게시물·의료광고 수정은 승인 범위를 먼저 확정하기. 보안 검사는 본인이 소유하거나 명시적으로 허가받은 로컬·스테이징 시스템에서만.
