# 모션 아카이브

수집한 모션그래픽 원문·이미지·HTML 데모를 HTML/CSS/JavaScript로 정리한 정적 사이트입니다.

## 포함 자료

- 원문 Markdown 33개, 원문 전체 보기와 다운로드
- 참고 이미지 87장, 확대 보기
- 모션 HTML 데모 46개, 격리된 iframe 미리보기
- 스타일 30종, 모션 46종, 카메라 46종의 개별 탐색 카드
- 사례 JSON 1개
- 제목·본문 검색, 카테고리 탭, 프롬프트 복사, 브라우저별 저장한 자료
- 167개 원본 파일의 목록과 SHA-256
- 기존 Notion 첨부 미확인 3개 표시

## 바로 보기

GitHub Pages는 저장소 루트의 index.html에서 바로 실행됩니다. 다시 빌드하면 dist 폴더가 생성됩니다.
클립보드와 데모는 HTTPS 또는 로컬 서버 환경에서 가장 안정적으로 동작합니다.
서버나 로그인 기능 없이 정적 파일만으로 동작하며 방문자 검색어와 저장한 자료는 서버로 전송하지 않습니다.

## 다시 만들기

Node.js와 npm이 있는 환경에서 npm install 후 npm run build를 실행합니다.
build.mjs는 source-manifest.json의 원본 문서·첨부로 data.js와 dist를 생성합니다.
원문 파일은 변형하지 않습니다. 화면에 필요한 링크만 렌더링 단계에서 변환합니다.

## GitHub Pages에 배포할 때

1. 이번 사이트용 새 저장소를 생성합니다.
2. dist 안의 파일과 assets, documents, demos 폴더를 저장소 루트에 올립니다.
3. Settings → Pages에서 해당 브랜치의 루트 폴더를 게시 대상으로 설정합니다.
4. GitHub가 표시하는 실제 게시 URL과 배포 완료 상태를 확인합니다.

기존 저장소의 공개 범위를 바꿀 필요는 없습니다. 새 저장소를 사용하세요.
GitHub에서 발급한 게시 URL만 공유하고 예상 주소를 완료된 주소로 안내하지 마세요.

## 파일

index.html: 페이지 구조  
styles.css: 반응형 화면  
app.js: 검색·탭·본문·복사·데모 상호작용  
data.js: 렌더링한 전체 콘텐츠  
inventory.json: 원본 파일 목록·해시·미확인 첨부  
documents/: 원문 Markdown 및 JSON  
assets/: 원본 이미지  
demos/: 원본 HTML 데모  
source-manifest.json, build.mjs: 재생성 도구

## 자료 보존

가이드 본문과 프롬프트는 원문 전체를 유지합니다. 각 자료에 포함된 출처를 함께 확인하세요.
기존 문서의 모델명·가격·제품 기능을 현재 정보로 보증하지 않습니다.
원래 있던 Notion 첨부 링크 3개는 파일을 확보하지 못했으며 원문을 보존하고 미확인으로 표시했습니다.
수집한 원본의 권리는 각 작성자에게 있습니다. 이 사이트에 포함했다는 이유로 일괄 재라이선스하지 않습니다.

## 검증 범위

원본 166개 파일의 바이트 크기를 Drive 목록과 대조했고, 신규 가이드 1개를 더했습니다.
167개 원본 파일의 SHA-256과 33개 Markdown 본문을 배포 파일과 대조해 일치를 확인했습니다.
122개 레퍼런스 카드, 87개 이미지 경로, 46개 데모 경로 및 스크립트 문법 검사를 통과했습니다.
Sites 배포 전 실제 브라우저 화면 검사는 지원되지 않아 수행하지 못했습니다.
