# 🎬 Opus 5.5로 5분만에 만드는 브랜드 홍보 영상 — 프롬프트 7개 전부 공개

> [!info] 🎬
> 캐러셀에서 보여준 영상 7개, 내가 실제로 넣은 프롬프트 그대로 + 내 브랜드로 바꿔 쓰는 빈칸 버전까지 다 넣었어.
>
> **영상 생성 툴 하나도 안 썼어.** Claude가 HTML 코드로 애니메이션을 짜고, 그걸 프레임마다 찍어서 MP4로 만든 거야. 그래서 생성 크레딧은 0원.

---

## 시작 전에 — 이거 3개만 알면 돼

### 1. 어디서 돌려?

- **Claude Code (Opus 5.5, 노력 '높음')** 추천. 파일 만들고, 렌더하고, MP4까지 한 번에 가.
- [claude.ai](http://claude.ai) 채팅에서도 돼. 다만 거기선 HTML 미리보기까지만 나오고, MP4 파일로 뽑으려면 아래 '마지막 단계' 프롬프트를 Claude Code에서 돌려야 해.

### 2. 결과를 가른 건 프롬프트 길이가 아니었어

1. **몇 초짜리인지 + 장면 순서를 화살표로** 적어주기 (A → B → C)
2. **색은 2~3개만** 박아두기 (HEX 코드로)
3. 나온 거 보고 **2~3번 고쳐달라고 하기** — "글자가 카드에 묻혀", "로고 방향 틀렸어"처럼 구체적으로

### 3. 마지막 단계 — MP4로 뽑는 프롬프트

영상 프롬프트 뒤에 이걸 붙이거나, 결과 나온 다음에 따로 시켜.

```text
모든 애니메이션은 시간 t의 함수로 짜줘. window.renderAt(t)를 부르면 그 순간 화면이 그려지게.
그다음 헤드리스 크롬으로 30fps마다 renderAt을 불러서 프레임을 캡처하고, ffmpeg로 MP4(H.264)를 만들어줘.
외부 CDN이나 웹폰트는 쓰지 말고, 폰트는 내 컴퓨터에 있는 파일 경로로 넣어줘.
렌더 전에 주요 장면 프레임 몇 장을 먼저 뽑아서 보여주고, 글자 겹침이나 잘림이 없는지 네가 먼저 확인해.
```

## 01 · 모션 쇼릴

> 내 쇼릴. 프롬프트 몇 줄로 12초. 공 튕김 → 큰 글자 → 점 격자 물결 → 사인파 → 3D 점 구체 → 로고.

### 내가 넣은 프롬프트

```text
네가 얼마나 대단한 모션 디자이너인지 보여주는 12초짜리 쇼릴을 만들어줘.
이력서에 붙이는 쇼릴이라고 생각하고, 끝까지 밀어붙여.

- 색: 크림 #F2EBDA · 코랄 #E84B2C · 잉크 #0E0C0A, 이 셋만
- 2초마다 새로운 기법 하나 (센터 텍스트 + 그라데이션 같은 뻔한 거 금지)
- 마지막은 MOONGI STUDIO 로고로 끝내기
- 16:9, 1920×1080, 30fps
```

### 빈칸 템플릿

```text
네가 얼마나 대단한 모션 디자이너인지 보여주는 [12]초짜리 쇼릴을 만들어줘.
이력서에 붙이는 쇼릴이라고 생각하고, 끝까지 밀어붙여.

- 색: [색1 HEX] · [색2 HEX] · [색3 HEX], 이 셋만
- 2초마다 새로운 기법 하나 (센터 텍스트 + 그라데이션 같은 뻔한 거 금지)
- 마지막은 [내 브랜드명] 로고로 끝내기
- 16:9, 1920×1080, 30fps
```

> [!tip] 💡
> "끝까지 밀어붙여"(go all out) 한 줄이 생각보다 커. 처음엔 한글 폰트가 안 잡혀서 명조로 떨어졌는데, "폰트 파일 경로로 넣어"라고 하니 해결됐어.

## 02 · 신제품 런칭 (MacBook Air 스펙 광고)

> Apple 키노트 스타일. 로고 인트로 → 두께 → 덮개 열림 → 칩 → 배터리 → 컬러 4종.

### 내가 넣은 프롬프트

```text
최신 MacBook Air(13형, M5) 스펙 광고를 14초짜리 HTML로 만들어줘 (1920×1080). 애플 키노트 영상처럼 절제되고 세련되게.
숫자는 Apple 공식 스펙 페이지에서 확인해서 써. 로고는 기억으로 그리지 말고 공식 SVG를 받아서 써.

- 검은 배경 위 Apple 로고가 블러에서 선명해지며 시작
- 노트북은 3D로 직접 만들어서 덮개가 실제로 열리게
- 모션은 튀지 않게: 오버슈트 없는 스프링, 글자는 블러+스케일로 스며들듯 등장
- 1.13cm · 1.23kg → 덮개 열림 "13.6형 Liquid Retina" → M5 칩 "10코어 CPU" → "최대 18시간"
- 컬러 4종은 열린 노트북 뒷모습으로 나란히
- 마지막: MacBook Air 워드마크 + "비공식 스펙 광고" 표기
```

### 빈칸 템플릿

```text
[제품명] 스펙 광고를 [14]초짜리 HTML로 만들어줘 (1920×1080). [브랜드] 발표 영상처럼 절제되고 세련되게.
숫자는 [제조사] 공식 스펙 페이지에서 확인해서 써. 로고는 기억으로 그리지 말고 공식 SVG를 받아서 써.

- 검은 배경 위 로고가 블러에서 선명해지며 시작
- 제품은 3D로 직접 만들어서 [움직이는 부분: 덮개/뚜껑/버튼]이 실제로 움직이게
- 모션은 튀지 않게: 오버슈트 없는 스프링, 글자는 블러+스케일로 스며들듯 등장
- [스펙1] → [스펙2] → [스펙3] → [스펙4]
- 컬러 [N]종 나란히
- 마지막: 제품 워드마크 + "비공식 스펙 광고" 표기
```

> [!warning] ⚠️
> 실제 브랜드로 만들면 **"비공식" 표기는 꼭** 넣어. 숫자는 공식 스펙에서만. 로고 방향이 두 번 틀려서, "로고 들어간 장면은 원본 SVG랑 확대해서 비교하고 보여줘"를 추가했더니 잡혔어.

## 03 · 제품 광고 (카드)

> 노랑+검정 두 색. 점이 터짐 → "국경 없이." → 클로즈업 → 회전하는 카드 + 혜택 칩 → 단어 연타 → 점 지구본 → 로고. (MOONGI CARD는 가상 브랜드야)

### 내가 넣은 프롬프트

```text
MOONGI 체크카드 15초 광고를 HTML로 만들어줘 (1920×1080).
두 색만 써: 노랑 #FFD400 + 거의 검정 #0E0E0E. 굵은 대문자급 타이포, 주인공은 3D로 도는 카드. 빠른 전환에 모션 블러 + 잔상.

- 브랜드: MOONGI CARD · 태그라인: 국경 없이, 한 장으로
- 장면: 빛나는 점이 터짐 → "국경 없이." → 카드 디테일 클로즈업 "디테일까지."
  → 카드가 돌고 주변에 혜택이 카드로 튀어나옴 (₩ $ € ¥ 코인, 잔액, 해외결제 토글)
  → "결제." "송금." "환전." 단어 연타 → 점으로 된 지구본 + "카드 한 장."
  → 로고 + 태그라인
```

### 빈칸 템플릿

```text
[제품] [15]초 광고를 HTML로 만들어줘 (1920×1080).
두 색만 써: [메인색 HEX] + 거의 검정 #0E0E0E. 굵은 타이포, 주인공은 3D로 도는 [제품]. 빠른 전환에 모션 블러 + 잔상.

- 브랜드: [브랜드명] · 태그라인: [한 줄]
- 장면: 빛나는 점이 터짐 → "[큰 카피 1]" → [제품] 디테일 클로즈업 "[카피 2]"
  → [제품]이 돌고 주변에 혜택이 카드로 튀어나옴 ([혜택1], [혜택2], [혜택3])
  → "[단어1]." "[단어2]." "[단어3]." 단어 연타 → [마무리 그래픽] + "[카피 3]"
  → 로고 + 태그라인
```

> [!tip] 💡
> 처음엔 "카드사 광고처럼"이라고만 했더니 카드 혼자 빙글빙글 도는 게 끝이었어. **레퍼런스 영상의 장면 순서를 화살표로 그대로 적어주니까** 그 구조가 나왔어.

## 04 · 앱 사용법 영상 (다스림)

> 내 앱 실제 화면 7장을 3D 폰에 넣고, 손가락이 직접 눌러가며 사용 순서를 보여줘.

### 내가 넣은 프롬프트

```text
내 앱 '다스림' 런칭 영상을 16초짜리 HTML로 만들어줘 (1920×1080). 앱스토어 런칭 광고 느낌으로.
첨부한 실제 앱 화면 7장(screens/)을 그대로 써. 화면을 새로 그리지 말고.

- 어두운 배경 + 코랄(#FF6B5C) 빛 번짐, 3D로 떠 있는 폰
- 사용 순서대로 손가락이 직접 눌러가며 보여주기:
  홈에서 마이크 탭 → 선배가 듣는 중(실시간 자막) → 정리 → 해석 A·B·C → 보낼 메시지 초안 → 카톡으로 보내기
- 단계마다 핵심 카드가 폰 밖으로 튀어나오기 (자막 말풍선, 해석 카드 3장, 메시지 초안)
- 왼쪽 헤드라인은 단계마다 바뀌고 키워드만 코랄
- 마지막: 폰 3대가 부채꼴로 펼쳐지고 → DASEURIM 로고 + "말로 털어놓으면, 정리해서 돌려드려요"
```

### 빈칸 템플릿

```text
내 앱 '[앱 이름]' 런칭 영상을 [16]초짜리 HTML로 만들어줘 (1920×1080). 앱스토어 런칭 광고 느낌으로.
첨부한 실제 앱 화면 [N]장을 그대로 써. 화면을 새로 그리지 말고.

- 어두운 배경 + [포인트색 HEX] 빛 번짐, 3D로 떠 있는 폰
- 사용 순서대로 손가락이 직접 눌러가며 보여주기:
  [화면1에서 누르는 것] → [화면2] → [화면3] → [화면4] → [완료 화면]
- 단계마다 핵심 카드가 폰 밖으로 튀어나오기 ([튀어나올 정보들])
- 왼쪽 헤드라인은 단계마다 바뀌고 키워드만 포인트색
- 마지막: 폰 3대가 부채꼴로 펼쳐지고 → [앱 로고] + "[한 줄 소개]"
```

> [!tip] 💡
> **화면 캡처를 첨부하는 게 핵심이야.** 가상 앱으로 만들면 예쁘기만 하고 사용법이 안 보여. 손가락이 누를 버튼 위치는 Claude가 캡처에서 알아서 찾아.

## 05 · 가게 오픈 홍보 (빵집)

> 오븐이 열리며 소금빵 등장 → 가게 이름 → 달력 + 시계 → 1+1 도장. 빵 사진 없이 빵까지 코드로 그렸어. (아침빵집은 예시야)

### 내가 넣은 프롬프트

```text
동네 빵집 '아침빵집' 오픈 홍보 영상 10초짜리 만들어줘. 인스타에 올릴 거야.

- 오픈: 10월 18일 토요일 오전 8시
- 첫 주 소금빵 1+1
- 따뜻하고 귀여운 느낌. 색은 크림·갈색·버터 노랑
- 빵 사진은 없으니까 빵도 직접 그려줘
- 16:9, 1920×1080
```

### 빈칸 템플릿

```text
우리 가게 '[가게 이름]' 오픈 홍보 영상 [10]초짜리 만들어줘. 인스타에 올릴 거야.

- 오픈: [날짜] [요일] [시간]
- 오픈 이벤트: [이벤트 한 줄]
- [분위기] 느낌. 색은 [색1]·[색2]·[색3]
- [대표 메뉴/상품] 사진은 없으니까 직접 그려줘
- 16:9, 1920×1080
```

## 06 · 숫자 리포트 (대시보드)

> 숫자가 슬롯머신처럼 굴러가고, 막대그래프 + 추세선 + 도넛 + 배지. (숫자는 전부 예시야)

### 내가 넣은 프롬프트

```text
우리 가게 월간 리포트를 8초짜리 모션 대시보드로 만들어줘.

- 이번 달 예약 1,284건 (숫자는 슬롯머신처럼 굴러가게)
- 5월~10월 월별 예약 막대그래프 + 추세선
- 재방문율 62% 도넛 차트
- 지난달 대비 +38% 배지
- 남색 배경 + 민트 포인트, 깔끔한 금융 앱 느낌
- 16:9, 1920×1080
```

### 빈칸 템플릿

```text
[내 가게/채널] 월간 리포트를 [8]초짜리 모션 대시보드로 만들어줘.

- 이번 달 [핵심 지표] [숫자] (숫자는 슬롯머신처럼 굴러가게)
- [기간] 월별 [지표] 막대그래프 + 추세선
- [비율 지표] [%] 도넛 차트
- 지난달 대비 [+N%] 배지
- [배경색] 배경 + [포인트색] 포인트, 깔끔한 금융 앱 느낌
- 16:9, 1920×1080
```

> [!tip] 💡
> 인스타 인사이트 숫자를 그대로 넣으면 월간 결산 콘텐츠가 바로 나와.

## 07 · 해설 영상 (Vox 스타일)

> 종이 질감 + 형광펜 + 손그림 동그라미. 망고가 지도 위 점선을 따라 농장에서 우리 집까지.

### 내가 넣은 프롬프트

```text
Vox 같은 에디토리얼 해설 영상 스타일로 10초짜리 만들어줘.
주제: 망고 한 개가 우리 집 냉장고까지 오는 길.

- 종이 질감 배경, 형광펜 밑줄, 손으로 그린 동그라미 표시
- 농장 → 후숙 → 배 → 마트 → 우리 집, 점선 경로를 따라 망고가 이동
- 카메라가 지도 위를 따라가듯 움직이기
- 마지막 한 줄: "다음 망고는 조금 더 소중하게"
- 16:9, 1920×1080
```

### 빈칸 템플릿

```text
Vox 같은 에디토리얼 해설 영상 스타일로 [10]초짜리 만들어줘.
주제: [설명하고 싶은 과정 한 줄].

- 종이 질감 배경, 형광펜 밑줄, 손으로 그린 동그라미 표시
- [단계1] → [단계2] → [단계3] → [단계4] → [단계5], 점선 경로를 따라 [주인공]이 이동
- 카메라가 지도 위를 따라가듯 움직이기
- 마지막 한 줄: "[마무리 카피]"
- 16:9, 1920×1080
```

> [!tip] 💡
> 처음 나온 망고가 귤처럼 동그래서 "길쭉한 콩팥 모양에 꼭지 달아줘"라고 한 번 고쳤어. 이런 한 줄 수정이 결과를 바꿔.
