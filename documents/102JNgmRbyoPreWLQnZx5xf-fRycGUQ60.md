# 모션그래픽 레퍼런스 (카드뉴스용)

Aside(Claude Opus 5.5)가 **HTML / CSS / SVG / Canvas 코드로 직접 구현할 수 있는 모션그래픽 스타일** 모음.
이미 공유한 3가지(손그림 캔버스 애니메이션, 아이폰 키노트식 쾅쾅 타이포, 서리 유리 폴더 UI)는 빼고 **20종**을 정리했다.
**2026-09-28 추가: 21~46번 26종** (덴서티 다국어판에서 실제로 쓴 전환·등장 기법 + gasket_love 기법 노트에서 빠져 있던 것). 모두 데모 HTML과 캡처가 있다.

- 모든 예시는 **1080×1350 (4:5 인스타 카드뉴스)** 기준
- 스크린샷은 애니메이션 **중간 한 프레임**. 실제 움직임은 `데모/` 폴더의 HTML을 크롬으로 열어서 확인
- 텍스트, 컬러, 폰트는 전부 바꿀 수 있고, 여러 스타일을 한 장 안에서 섞는 것도 가능

## 01. 에디토리얼 매거진 (Editorial Magazine)

![[01_에디토리얼_매거진.jpg|420]]

**어떤 모션:** 크림 배경에 세리프 대형 타이포가 한 줄씩 마스크 속에서 올라오고, 가는 괘선이 좌→우로 그어지며, 원형 컬러 오브제가 커지면서 등장. 잡지 표지 느낌.
**핵심 기법:** 줄 단위 마스크 슬라이드업, 괘선 scaleX 드로잉, 스태거(시차) 등장
**잘 어울리는 곳:** 브랜드 스토리 첫 장, 시즌 캠페인 표지, 고급 시술/제품 소개

**예시 프롬프트**
> 01 에디토리얼 매거진 스타일로 카드뉴스 표지 만들어줘. 크림 배경 + 명조 계열 대형 타이포, 제목은 "가을, 피부가 다시 채워지는 계절". 한 줄씩 아래에서 올라오게, 상단에 잡지 이름처럼 "BEAUTY BLOSSOM" 넣고 포인트 컬러는 테라코타.

## 02. 리퀴드 블롭 모핑 (Gooey / Metaball)

![[02_리퀴드_블롭.jpg|420]]

**어떤 모션:** 그라디언트 방울 여러 개가 둥둥 떠다니다가 서로 닿으면 물방울처럼 녹아 붙고 떨어짐.
**핵심 기법:** SVG goo 필터(블러 + 알파 대비), 궤도 애니메이션
**잘 어울리는 곳:** "하나로 합쳐진다", "스며든다" 같은 메시지, 제품 콘셉트 오프닝

**예시 프롬프트**
> 02 리퀴드 블롭 스타일로, 핑크-코랄 그라디언트 방울들이 합쳐지는 배경 위에 "피부 속까지 스며드는 수분" 문구. 방울이 마지막에 하나로 합쳐지면서 문구가 뜨게 해줘.

## 03. 오로라 메쉬 그라디언트 (Aurora Gradient)

![[03_오로라_그라디언트.jpg|420]]

**어떤 모션:** 어두운 배경 위에서 여러 색 빛 덩어리가 천천히 흐르며 섞임. 필름 그레인 질감 + 유리 알약 배지.
**핵심 기법:** Canvas 방사형 그라디언트 + 대형 블러 + 가산 합성, 노이즈 오버레이
**잘 어울리는 곳:** 신제품/신규 시술 런칭, 감성 브랜딩, 배경 루프 영상

**예시 프롬프트**
> 03 오로라 그라디언트 배경으로 5장 전체 톤 통일해줘. 컬러는 라벤더, 민트, 피치. 첫 장 문구 "당신의 빛을 깨우는 시간", 그레인 질감 살짝.

## 04. 파티클 글자 조립 (Particle Assemble)

![[04_파티클_조립.jpg|420]]

**어떤 모션:** 화면에 흩어진 수천 개의 점이 날아와 글자/숫자/로고 모양으로 조립됨 (반대로 폭발 해체도 가능).
**핵심 기법:** 텍스트를 픽셀로 샘플링 → 입자별 목표점 이징 이동
**잘 어울리는 곳:** 오픈 D-7, 카운트다운, 로고 등장 엔딩

**예시 프롬프트**
> 04 파티클 조립으로 "D-3" 숫자가 금색 입자로 모이게 하고, 다 모이면 아래에 "그랜드 오픈 이벤트" 문구 페이드인. 마지막 장은 입자가 로고로 모이게.

## 05. 스플릿 플랩 전광판 (Split-flap Board)

![[05_스플릿_플랩.jpg|420]]

**어떤 모션:** 공항 출발 안내판처럼 칸마다 글자가 촤라락 넘어가다가 한 글자씩 멈추며 문구 완성.
**핵심 기법:** 상/하 반쪽 타일 + 3D 회전 플립, 칸별 정지 시점 시차
**잘 어울리는 곳:** 특가 발표, 이벤트 일정, "다음 목적지는 ○○" 식 카피

**예시 프롬프트**
> 05 스플릿 플랩으로 "추석특가" / "최대30%" 두 줄이 차례로 멈추게 해줘. 위에 "DEPARTURE · 출발 안내" 라벨, 아래 "탑승 마감 10월 5일".

## 06. 데이터 카운트업 차트 (Data Count-up)

![[06_데이터_카운트업.jpg|420]]

**어떤 모션:** 큰 숫자가 0부터 올라가고, 도넛 링이 그려지고, 막대그래프가 순서대로 자라남.
**핵심 기법:** 숫자 이징 카운트, SVG stroke 도넛, 막대 스태거
**잘 어울리는 곳:** 만족도, 재방문율, 누적 고객 수, 성과 증명 장
**주의:** 실제 수치만 넣기 (예시 수치면 "예시" 표기 필수)

**예시 프롬프트**
> 06 데이터 카운트업 스타일로 "누적 고객 12,000명" 숫자가 올라가고, 옆에 월별 막대그래프. 수치는 내가 줄게: 1월 320, 2월 410, 3월 560. 블루 톤 깔끔하게.

## 07. 글리치 RGB 스플릿 (Glitch)

![[07_글리치.jpg|420]]

**어떤 모션:** 글자가 빨강/청록으로 찢어지고, 가로 줄이 튀고, 화면이 순간적으로 흔들림. 스캔라인 + 에러 코드.
**핵심 기법:** 레이어 3장 오프셋 + clip-path 슬라이스, steps() 끊김 애니메이션
**잘 어울리는 곳:** 스크롤 멈추게 하는 첫 장 후킹, "기존 방식은 끝" 같은 반전 메시지

**예시 프롬프트**
> 07 글리치로 첫 장 후킹 만들어줘. "그 방법, 틀렸어요" 문구가 3번 찢어졌다가 선명해지게. 검정 배경, 너무 과하지 않게 0.5초 간격.

## 08. SVG 라인 드로잉 (Line Drawing)

![[08_라인_드로잉.jpg|420]]

**어떤 모션:** 펜으로 그리듯 선이 따라가면서 일러스트(병, 잎, 반짝임)가 완성됨.
**핵심 기법:** stroke-dasharray / dashoffset 드로잉, 파트별 순차 딜레이
**잘 어울리는 곳:** 성분/원료 이야기, 과정 설명, 미니멀 브랜딩

**예시 프롬프트**
> 08 라인 드로잉으로 앰플 병과 꽃잎이 그려지고, 다 그려지면 "자연에서 온 단 한 방울" 문구. 베이지 배경, 포인트 선 하나만 테라코타.

## 09. 마스크 리빌 와이프 (Mask Reveal)

![[09_마스크_리빌.jpg|420]]

**잘 어울리는 곳:** 비포/애프터, 반전 공개, 챕터 전환

**예시 프롬프트**
> 09 마스크 리빌로 2번 장 만들어줘. 어두운 화면에서 원이 퍼지면서 코랄 그라디언트가 열리고 "가려져 있던 / 진짜 피부결을 / 드러낼 때" 세 줄이 와이프로 등장.

## 10. 아이소메트릭 3D (Isometric)

![[10_아이소메트릭.jpg|420]]

**어떤 모션:** 비스듬한 3D 바닥 위로 블록들이 통통 튀며 솟아오르고, 마지막 블록에 라벨이 붙음.
**핵심 기법:** CSS 3D(rotateX/Z) 아이소 뷰, 높이 스프링 애니메이션
**잘 어울리는 곳:** 단계별 과정(1주차~4주차), 성장, 구조 설명

**예시 프롬프트**
> 10 아이소메트릭으로 "관리 4단계" 블록 4개가 순서대로 솟아오르게. 블록마다 "상담 / 진단 / 케어 / 유지" 라벨, 마지막 블록만 오렌지.

## 11. 네온 사인 (Neon)

**잘 어울리는 곳:** 야간 이벤트, 팝업스토어, 힙한 톤 공지

**예시 프롬프트**
> 11 네온 사인으로 "금요일 밤 / 연장 영업" 핑크+민트 네온. 하트 네온이 먼저 그려지고 글자가 지직 켜지게.

## 더 가능한 것들 (데모 없음, 요청하면 구현 가능)

- **잉크 번짐 / 수채화 번짐:** SVG 난류 필터로 잉크가 퍼지며 글자 등장
- **홀로그램 포일 카드:** 기울이면 무지갯빛이 흐르는 카드
- **Y2K 크롬:** 크롬 입체 글자, 타임코드 (VHS 쪽은 29·33번으로 구현됨)
- **무한 줌 (드로스테):** 화면 속 화면으로 계속 빨려 들어가는 전환
- **하프톤 / 도트 매트릭스:** 점 크기로 이미지와 글자를 표현
- **스와이프 카드 스택:** 틴더처럼 카드가 넘어가며 다음 내용 등장
- **WebGL 셰이더 / Three.js 3D:** 진짜 3D 오브젝트 회전, 물결, 유체 배경
- **실사 사진/영상 합성:** 무료 스톡 영상이나 AI 이미지 위에 위 모션들을 오버레이 (GPT 누끼 모델·장비는 이미 사용 중)
- **키워드 변형 타이포:** 뜻대로 움직이는 글자 ("누르다"는 눌리고 "쪼개다"는 띠로 갈라짐). 태국어는 자소 덩어리 단위로 쪼개야 깨지지 않음

**결론: 기본 20종 + 추가 26종(21~46) + 위 7종 + 이미 공유한 3종 = 약 56종.** 서로 섞으면 사실상 무한대 (예: 채팅 후킹 → 마스크 리빌 전환 → 데이터 카운트업 → 벤토 요약 → 파티클 로고 엔딩).
