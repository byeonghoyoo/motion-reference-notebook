> **사용법**

> `[원하는 장면] + [인물의 행동] + [카메라 움직임] + [아래 스타일 프롬프트]`


예시

```

```

## 프롬프트를 더 잘 쓰는 4가지 팁

1. **스타일 키워드는 3~5개만** 사용하세요. 너무 많이 넣으면 분위기가 섞여요.
2. 영상에는 `slow camera push-in`, `smooth orbit camera`, `gentle handheld motion`처럼 **카메라 움직임**을 하나 추가하세요.
3. 캐릭터를 계속 등장시킬 때는 `same character, consistent outfit, consistent facial features`를 함께 넣으세요.
4. 영상이 깨지거나 흔들리면 `clean details, stable composition, natural motion, no distortion`을 덧붙여보세요.

```
[주인공과 장소], [행동], [시간대와 조명], [카메라 움직임], [스타일 키워드 3~5개], clean details, stable composition, natural motion, high quality
```
