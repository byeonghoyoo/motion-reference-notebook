### A. 모션그래픽 프리셋·템플릿 — 프리뷰 보고 골라서 바로 쓰는 용도 (EYE-CUT 직결)

**1. HyperFrames 카탈로그** ⭐ 이미 네 스택이야

- 우리가 깐 그거. `npx hyperframes add flash-through-white`(셰이더 트랜지션), `instagram-follow`(소셜 오버레이), `data-chart`(애니메이션 차트)처럼 카탈로그에서 블록을 골라 설치. [Steve Kinney](https://stevekinney.com/courses/ai-development/claude-code-and-bash-scripts)
- 프리뷰 갤러리: **hyperframes.heygen.com/catalog** — 프리뷰 보고 이름 확인 → `npx hyperframes add <이름>`으로 EYE-CUT motion/에 바로 추가. 50개+ 블록.

**2. Jitter 템플릿** — 프리뷰 제일 풍부, UI·SNS 모션 특화

- jitter.video/templates — 로딩 스피너, 그라디언트 모핑, 토글버튼, 픽셀 디졸브 트랜지션, 블렌드모드 콜라주, 결제 알림 등 무료 모션 템플릿이 전부 움직이는 프리뷰로 깔려있어. 스타일 영감 + "이런 느낌" 고르기 좋음. [Epidemicsound](https://help.epidemicsound.com/hc/en-us/articles/31033671901458-How-to-Import-Your-Audio-Timeline-XML-FCPXML-and-Relink-Files)

**3. Remotion prompt-to-motion-graphics** — 프롬프트→모션 코드 생성형

- 프롬프트 입력 → 검증 → 스킬 감지 → 코드 생성 → 브라우저 라이브 프리뷰. 차트·타이포·트랜지션 도메인별 패턴 라이브러리 포함. HyperFrames랑 같은 결이라 참고용. [GitHub](https://github.com/ChatOctopus/timeline)

### B. 이미지 프롬프트 라이브러리 — 프리뷰 + 복붙 프롬프트 (너 GPT-Image-2 작업용)

**4. awesome-gpt-image-2** (YouMind) ⭐ 너한테 딱

- 세계 최대 GPT Image 2 프롬프트 라이브러리, 매일 업데이트. 2000+ 큐레이팅 프롬프트 + 프리뷰 이미지, 16개 언어. 무료 오픈소스. github.com/YouMind-OpenLab/awesome-gpt-image-2 [Rev](https://www.rev.com/blog/how-to-import-an-edit-decision-list-edl-into-final-cut-pro)

**5. awesome-nano-banana-pro-prompts** (YouMind) — 규모 미쳤음

- 10,000+ 큐레이팅 프롬프트 + 프리뷰 이미지, 16개 언어. 구글 Gemini AI 이미지 생성. 무료 오픈소스. github.com/YouMind-OpenLab/awesome-nano-banana-pro-prompts [GitHub](https://github.com/DareDev256/fcpxml-mcp-server)

**6. awesome-gptimage2-prompts** (erickkkyt) — 가볍고 복붙 편함

- 프리뷰 이미지 + 복붙 가능한 프롬프트로 큐레이팅된 GPT-Image-2 라이브러리. 무료 오픈소스. [ClaudeCode101](https://claudecode101.com/en/tutorial/advanced/headless-mode)

### C. 보너스 — 무료 오픈소스 모션 에디터 (손으로 직접 만질 때)

- **Motionity**: 웹 기반 무료 오픈소스 애니메이션 에디터. After Effects + Canva 믹스. 키프레이밍·마스킹·크로마키·Lottie 지원, Pixabay 통합, 로그인 없이 무료. 가입 없이 바로 씀. [PremiumBeat](https://www.premiumbeat.com/blog/xml-files-premiere-fcpx-davinci/)
