01 · CONCEPT

뭐가 되는 거야?

이미지 생성 모델이 아니라 '그림 그리는 코드'

완성 이미지

77가지 화풍 중 하나로 장면을 그려 JPG/PNG로 저장.

draw-on 애니메이션

그리는 중간 단계를 프레임으로 저장 → 한 획씩 그려지는 영상.

장면 교체

화풍 코드는 그대로 두고 장면(scene)만 바꾸면 파리·강남·북촌 무엇이든 같은 화풍으로.

왜 코드로?

구도·여백을 정확히 지정 가능, 같은 seed면 같은 결과(재현성), 그리는 과정 애니메이션 가능, 오프라인·CPU만으로 동작.

저작권 메모 · 이미지 생성 모델을 쓰지 않으니 학습 데이터 논란에서는 자유로운 편이고, 스킬 코드는 MIT 라이선스야. 다만 실존 브랜드 로고·캐릭터·건물 디자인을 그대로 그리게 하면 그건 별개 문제라 상업 소재에선 피하는 게 안전해.
02 · INSTALL

설치 (3분)

Claude Code가 이미 있다는 전제

1. 스킬 클론2. 의존성 설치3. 재시작
STEP 1 · 스킬 클론

터미널에서 Claude Code 스킬 폴더로 받아와.

터미널 · 스킬 클론
git clone https://github.com/cloveric/claude-drawing-skill.git ~/.claude/skills/claude-drawing
STEP 2 · 파이썬 의존성

노션 글엔 빠져 있는 단계. 안 하면 첫 실행에서 모듈 에러가 나.

터미널 · 의존성 설치
pip install -r ~/.claude/skills/claude-drawing/requirements.txt # numpy, Pillow
STEP 3 · Claude Code 재시작

재시작하면 스킬을 자동 인식. ~/.claude/skills/claude-drawing/examples/에 화풍별 완성형 코드 79개가 들어와 있어. 하나 = 한 화풍·한 장면.

폴더 이름은 자유야. 노션처럼 claude-drawing-skill로 받아도 동작하고, 아래 경로만 그 이름으로 바꿔 읽으면 돼. 한글 글씨가 깨지면 INKPAINT_FONT=/폰트/경로.ttf 환경변수로 폰트를 지정.
첫 실행 테스트 · Claude Code에 입력
claude-drawing 스킬로 colortown_festival_steps 돌려서 완성 이미지 뽑아줘.
03 · USAGE

사용법 3가지 패턴

파일명만 바꾸면 어느 화풍이든 동일

① 완성 이미지만 뽑기

PROMPT · 완성 이미지
claude-drawing 스킬에서 cyberpunk_neon_street 돌려서 완성 이미지 뽑아줘. 세로 1080×1350으로.

② 한 획씩 그려지는 애니 (추천)

PROMPT · draw-on 애니 mp4
cyberpunk_neon_street 화풍으로 한 획씩 그려지는 draw-on 애니 영상 만들어줘. --stages 옵션으로 중간 프레임 전부 뽑고, ffmpeg로 6초짜리 세로 1080×1350 mp4로 조립해줘. 인스타 릴스에 바로 올릴 수 있게.

뒤에 자유롭게 덧붙이면 돼 · 길이: "4초로", "10초로" · 비율: "가로 1920×1080", "정사각 1080×1080" · 속도: "천천히 그려지게", "빠르게 그리고 마지막 2초 멈춤".

③ 화풍은 유지, 장면만 바꾸기

PROMPT · 장면 교체
jiangnan_spring_water.py를 복사해서 장면만 내가 말하는 대로 바꿔줘. 붓·먹·색감 같은 화풍 요소는 그대로 유지. 장면: (위치 · 사물 · 인물 · 시간대 · 날씨를 한 문장으로)

직접 터미널로 돌릴 때

터미널 · 이미지 + 단계 프레임 → MP4
cd ~/.claude/skills/claude-drawing # 1. 완성 이미지 + 그리는 중간 단계 저장 # stages 폴더에 00_newsprint.png, 01_key_setting.png … NN_final.png 식으로 쌓임 python3 examples/comic_rocket.py out.jpg --stages ./stages # 2. 단계 PNG → 세로 1080×1350 MP4 # -framerate = 초당 몇 장 넘길지 (단계가 보통 7~20장이라 1~3 추천, 낮을수록 천천히) # tpad = 마지막 완성 장면을 2초 더 보여줌 ffmpeg -framerate 2 -pattern_type glob -i 'stages/*.png' \ -vf "scale=1080:1350:force_original_aspect_ratio=decrease,pad=1080:1350:(ow-iw)/2:(oh-ih)/2,tpad=stop_mode=clone:stop_duration=2,fps=30" \ -pix_fmt yuv420p draw.mp4 # (선택) GIF가 필요하면 ffmpeg -framerate 2 -pattern_type glob -i 'stages/*.png' -vf "scale=720:-1" draw.gif
노션 원문의 stages/%03d.jpg 패턴은 실제 파일명(00_이름.png)과 안 맞아서 그대로 치면 에러가 나. 위처럼 -pattern_type glob -i 'stages/*.png'로 받으면 이름 순서대로 정렬돼. 또 단계 수가 화풍마다 7~20장 정도라, "6초"를 맞추려면 framerate를 단계 수 ÷ 원하는 초로 계산하면 돼. Claude에게 맡기면 이것까지 알아서 맞춰줘.

05 · QUALITY

퀄리티 올리는 4가지

기본값만 돌리면 샘플과 똑같이 나옴

① 장면 묘사는 아주 구체적으로

✕ "파리 거리 그려줘"
✓ "몽마르트르 언덕 계단 옆 노천카페, 계단에 앉아 크루아상 먹는 커플, 멀리 사크레쾨르 성당과 에펠탑, 해 지기 30분 전 황금빛"

키워드 3개보다 구체적인 문장 1개가 훨씬 잘 나와. 위치 · 사물 · 인물 · 시간대 · 날씨를 다 넣어.

② 화풍 요소는 건드리지 말 것

✕ "수채화는 더 부드럽게, 선은 연하게"
✓ 화풍은 샘플 그대로, 장면 묘사만 바꾸기

각 화풍은 종이·붓·물감 규칙이 코드로 이미 잡혀 있어서, 화풍을 손대면 오히려 '그 재질답게' 보이는 느낌이 깨져. 한 번에 한 화풍만 쓰고 섞지 마.

③ 비율·구도 명시

용도크기
인스타 릴스·캐러셀(세로)1080×1350
쇼츠·릴스 풀세로1080×1920
유튜브(가로)1920×1080
인스타 단일(정사각)1080×1080

구도도 말로 지정하면 더 잘 나와 · 예: "주인공은 화면 왼쪽 1/3, 포인트 조명은 오른쪽 위". 예제마다 원래 크기가 달라(예: cyberpunk 1920×1080 가로, colortown 1500×2000 세로). 좌표가 원래 크기 기준으로 짜여 있어서 숫자만 바꾸면 구도가 틀어질 수 있으니, "1080×1350에 맞게 구도까지 다시 배치해줘"라고 요청하거나 ffmpeg 단계에서 여백(pad)·크롭으로 맞추는 게 안전해.

④ 부분 수정 요청하기

첫 결과 보고 "하늘이 너무 파래, 더 흐리게" 처럼 말하면 Claude가 .py에서 해당 줄을 찾아 고쳐줘. 같은 seed라 나머지는 그대로 유지돼.
