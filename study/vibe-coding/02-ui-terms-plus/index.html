1920px 화면 · 콘텐츠 1200px
Container
시술 안내

본문은 너무 넓게 퍼지지 않도록 최대 폭 안에서만 보여줘요. 한 줄이 너무 길면 읽기 힘들거든요.

⚠ 한 줄이 너무 길어져서 읽기 힘듦
넓은 화면에서도 콘텐츠(점선 상자)는 1200px 이상 안 커져. 꺼보면 끝까지 늘어나.
.container{
  max-width:1200px;   /* 이 이상은 안 넓어짐 */
  margin:0 auto;      /* 남는 공간을 양옆에 나눠 = 가운데 정렬 */
  padding:0 16px;     /* 좁은 화면에선 양옆 여백 */
}

<main class="container"> ...모든 콘텐츠... </main>
외우기물 붓는 컵(container). 화면이 아무리 넓어도 내용은 컵 크기(최대 폭)까지만 퍼짐.
실전 프롬프트
전체 콘텐츠를 max-width 1200px 컨테이너 안에 가운데 정렬하고, 모바일에서는 좌우 16px 여백을 줘.

슬라이더를 움직여서 768·1024 선을 넘어봐. 켜지는 CSS 줄(초록)이 바뀌어.
/* 모바일 먼저(mobile-first) 쓰고, 넓어질 때마다 덮어쓰기 */
.grid{grid-template-columns:1fr}

@media (min-width:768px){            /* BP ① 태블릿 */
  .grid{grid-template-columns:repeat(2,1fr)}
}
@media (min-width:1024px){           /* BP ② PC */
  .grid{grid-template-columns:repeat(3,1fr)}
}
Tailwind 기본값: sm 640 · md 768 · lg 1024 · xl 1280 · 2xl 1536 (px). “md:”가 붙으면 768px 이상에서만 적용.
외우기반응형이 “꺾이는(break) 지점(point)”. 우선 768(태블릿) · 1024(PC) 두 숫자만 외워.
실전 프롬프트
브레이크포인트는 768px(태블릿), 1024px(PC) 두 개로 잡고, 모바일 우선(mobile-first)으로 CSS를 작성해줘.

Pagination

페이지네이션

긴 목록을 여러 페이지로 나누고 1·2·3 번호로 이동하는 UI

oo-clinic.kr/review?page=1
후기
    Pagination
    const perPage = 3;
const total = Math.ceil(items.length / perPage);
const pageItems = items.slice((page-1)*perPage, page*perPage); // 이번 페이지 몫만

prevBtn.disabled = page === 1;      // 첫 페이지면 ‘이전’ 못 누름
nextBtn.disabled = page === total;  // 마지막이면 ‘다음’ 못 누름
history.replaceState(null, '', '?page=' + page); // 주소에 반영
    외우기책 페이지(page) 넘기듯 1·2·3 번호로 나눠 보기. 위치가 분명해서 “아까 그거” 다시 찾기 쉬움.
    실전 프롬프트
    후기 목록을 한 페이지 6개씩 페이지네이션으로 나누고, 이전/다음 버튼과 현재 페이지 강조, URL에 ?page=2처럼 반영해줘.

        Count-up
        화면에 들어오면 자동으로 0부터 올라가. 처음엔 빠르게, 끝에서 천천히(ease-out).
        function countUp(el, to, ms = 1500){
  const t0 = performance.now();
  requestAnimationFrame(function tick(now){
    const p = Math.min((now - t0) / ms, 1);   // 진행률 0 → 1
    const eased = 1 - Math.pow(1 - p, 3);      // ease-out: 끝에서 천천히
    el.textContent = Math.round(to * eased).toLocaleString();
    if(p < 1) requestAnimationFrame(tick);
  });
}

6. 폼: 이름·연락처·동의 Form Validation, 검색 결과 없음은 Empty State.
7. 모션: 등장 Easing은 ease-out 0.3s, 숫자 Count-up, 제휴 로고 Marquee, 팝업 뒤 Overlay 60%.
8. 성능: 첫 화면 이미지를 뺀 나머지는 Lazy Loading.
9. 스타일: 색·간격·둥글기는 Design Token(CSS 변수)으로, 라이트/Dark Mode 지원.
10. 모든 버튼은 default·hover·active·focus·disabled 5가지 UI State.
