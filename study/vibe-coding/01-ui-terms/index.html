24개 용어를 실전에 조합하는 법

영상의 핵심 공식은 UI 용어 + 원하는 동작 + 적용 조건이야. 아래 통합 예시는 원본 영상의 원칙을 바탕으로 학습용으로 새롭게 구성했어.

20~30대 방문자를 위한 피부미용 클리닉 랜딩페이지를 구현해줘.

1. 첫 화면: 헤드라인, 짧은 설명, 예약 CTA, 대표 이미지를 넣은 Hero Section.
2. 주요 서비스: 핵심 시술은 큰 카드, 나머지는 작은 카드로 보여주는 Bento Grid.
3. 내비게이션: 스크롤에도 유지되는 Sticky Header.
4. 시술 상세 정보: Overview / Procedure / FAQ 탭. FAQ는 Accordion.
5. 필터: 오른쪽에서 열리는 Drawer, 바깥 클릭과 ESC로 닫기.
6. 모션: 카드 Hover, Scroll Reveal, 0.1초 간격 Stagger Animation.
7. 성능/접근성: 반응형, 키보드 조작, 충분한 색 대비, reduced-motion 존중.
8. 저장 완료 피드백은 3초 Toast. 로딩 중에는 Skeleton UI.

반드시 PC·태블릿·모바일 레이아웃을 모두 구현하고 각 인터랙션을 작동하게 만들어줘.

추가 학습 메모: Scroll Reveal은 Intersection Observer를, 반응형은 CSS media query를, Reduced Motion은 prefers-reduced-motion 미디어 쿼리를 활용할 수 있어.
